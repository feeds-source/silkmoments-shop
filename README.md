# Silk Moments

Femme silk atelier shop (TanStack Start PWA) and the Shopify Online Store 2.0 theme.

## Shopify theme

Ready-to-upload theme lives in [`shopify-theme/`](./shopify-theme) and as its own repo:

**[github.com/feeds-source/femme-silk-atelier](https://github.com/feeds-source/femme-silk-atelier)** (`main`)

Zip: `public/Femme-Silk-Atelier.zip`  
Shopify: Online Store → Themes → Upload zip file.

## App (this repo)

```
npm install
npm run dev
```

Preview shop, bag, sizes, size guide, inventory. Cloudflare Worker shop remains on [vite-react-template](https://github.com/feeds-source/vite-react-template).
